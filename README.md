# Población de referencia y alcance de CRECE

Landing page con el recálculo de la población de referencia de 18 a 70 años, el desarrollo de las operaciones y un escenario de alcance hasta marzo de 2028.

Incluye definiciones de población, fuentes de INEI, referencias metodológicas a Spectrum y ONUSIDA, y un visor territorial de Lima Metropolitana–Callao y Tumbes.

Elaboración: Noam López Villanes — Consultor en Monitoreo y Evaluación.

Los resultados de tamaño poblacional basados en los porcentajes del PIP y el alcance de las actividades se presentan como escenarios de planificación con sus supuestos. Este repositorio contiene únicamente la página publicada y resultados agregados; no contiene registros personales ni bases internas.

Implementación: documento Quarto con cálculos en Python, exportado a HTML autocontenido, CSS y JavaScript. Cartografía provincial de los archivos INEI 2023 / GeoGPSPerú proporcionados para el análisis.

Fecha de los cálculos: 8 de noviembre de 2026.
